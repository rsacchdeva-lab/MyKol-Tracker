MY KOL TRACKER — ANDROID PROJECT

This is a simple Android wrapper around the HTML tracker you supplied. It displays the existing tracker locally in an Android app window.

IMPORTANT LIMITATION
This first version is a personal-use shell for the existing HTML guide/watchlist link. It does NOT yet monitor Solana wallets, read Pump.fun activity, or send live buy/sell alerts. Those require a wallet-data source/API and a separate monitoring service.

BUILD THE APK
1. Install Android Studio on a Windows, Mac, or Linux computer.
2. Open Android Studio and choose Open.
3. Select this folder: MyKOLTrackerAndroid
4. Let Android Studio sync/download the Android build components.
5. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show a link to the generated APK. Transfer it to your Pixel and tap it to install. You may need to allow installation from that file app.

The app does not request account credentials, wallet keys, or seed phrases.
